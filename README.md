# DevQuest---Game-to-study-about-Software-Engineer

DevQuest — Academia do Código! 🎮💜

Um jogo interativo baseado nos seis PDFs da faculdade, reunindo mais de 60 desafios para estudar e revisar os conteúdos.

O que você encontrará
- 🗺️ Seis mundos, um para cada aula.
- ⭐ Sistema de XP, níveis e sequência de acertos.
- 🧠 Perguntas teóricas e desafios de código.
- 💡 Explicações após cada resposta.
- 🃏 Flashcards para memorização.
- 🔄 Revisão automática das questões erradas.
- ⚔️ Chefão final com 18 desafios e três vidas.
- 🏆 Progresso salvo automaticamente no navegador.
Como jogar: baixe o arquivo e abra-o com dois cliques no Chrome ou Edge. Não precisa instalar nada, configurar servidor ou ter internet.

Bom estudo e boa aventura! ✨
